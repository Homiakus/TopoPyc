## ⏱️ Что это за проект за 10 секунд?

Python удобен для написания кода, но работает медленно: каждое число упаковывается в тяжелый объект (`PyObject`), а циклы тормозят из-за постоянных проверок типов и блокировок GIL.

**TopoPyc решает эту проблему раз и навсегда:**
1. Вы добавляете **одну строчку `@topojit`** перед обычной функцией на Python.
2. TopoPyc анализирует структуру связей и типов вашего кода с помощью продвинутой топологической математики.
3. Код мгновенно компилируется в машинный код (AVX/FMA) напрямую под ваш процессор — **без накладных расходов интерпретатора и без сборок мусора**.

## 🚀 Как начать за 1 минуту

### 1. Установка
```bash
# Рекомендуемый способ через uv:
uv tool install --force .

# Или через pip:
pip install .
```

### 2. Ускорение функции одной строчкой (`@topojit`)
```python
from topopyc import topojit
from math import sin

@topojit
def calculate_field(steps: int, dt: float) -> float:
    pos = 0.0
    vel = 1.0
    for i in range(steps):
        force = -sin(pos) * 2.5
        vel += force * dt
        pos += vel * dt
    return pos

# При вызове функция компилируется в нативный ассемблер и летит на пределе процессора:
print(calculate_field(10_000_000, 0.001))
```

### 3. Компиляция Python-скрипта в готовый бинарник (CLI)
```bash
# Превратить скрипт в автономный исполняемый файл без Python:
topopyc my_script.py -o my_app
./my_app

# Собрать быструю C-библиотеку для импорта (.so):
topopyc my_script.py --so -o my_module.so
```

## 💡 Почему это работает так быстро? (Просто о сложном)

Обычные JIT-компиляторы (PyPy, Numba) пытаются *угадывать* типы во время работы. Если предположение не совпало — программа резко тормозит.

**TopoPyc работает иначе:**
* **Никаких лишних объектов в памяти**: Все промежуточные переменные цикла живут напрямую в регистрах процессора, а не в куче.
* **Математическая гарантия типов**: Вместо догадок компилятор строит карту зависимостей алгоритма и строго доказывает постоянство типов.
* **Слияние операций (Kernel Fusion)**: Соседние математические действия склеиваются в одну быструю векторную инструкцию процессора (FMA/AVX).
* **Симплектическая память**: Компилятор заранее знает, когда переменная больше не нужна, освобождая ресурсы мгновенно и без сборщика мусора (Zero GC).
