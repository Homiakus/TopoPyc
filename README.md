**TopoPyc** — высокоэффективный JIT и AOT компилятор для Python нового поколения, построенный на математическом аппарате **многомерной топологической голографии и высших клеточных пучков Ходжа** ($\Delta_k = d_{k-1}d_{k-1}^* + d_k^* d_k$).

Компилятор решает фундаментальные проблемы медленной работы Python (упаковка `PyObject`, динамический duck typing, циклы) путем построения симплициального комплекса программы и аналитического сведения препятствий когомологий $H^1 \to 0$ и $H^2 \to 0$. Результат — автоматическая трансляция в машинный код с **нулевыми накладными расходами памяти** и производительностью на уровне чистого C/Rust.

---

## 🚀 Основные преимущества

- **Декоратор одной строки `@topojit`**: Ускоряйте критические участки кода без модификации логики.
- **100% Unboxed Native Execution**: Исключение 24-байтовых заголовков объектов `PyObject` и атомарного подсчета ссылок для внутренних переменных.
- **Топологическая оптимизация когомологий**:
  - $H^0$: Доказательство мономорфизма типов сечений.
  - $H^1$: Устранение ветвлений динамического полиморфизма (duck typing).
  - $H^2$: Проверка отсутствия дедлоков и гонок данных в корутинах и циклах.
- **AOT & JIT режимы**: Возможность генерации как динамических расширений CPython (`.so`), так и полностью автономных бинарных исполняемых файлов (ELF).

## 📦 Установка

### Требования
- Python >= 3.10
- Системный компилятор C: `gcc` (рекомендуется) или `clang`
- Заголовочные файлы Python (`python3-dev`)
- Пакетный менеджер `uv` или стандартный `pip`

```bash
# Клонирование репозитория
git clone git@github.com:Homiakus/TopoPyc.git
cd TopoPyc

# Установка зависимостей через uv
uv sync
# или через pip
pip install -e .
```

## 💡 Руководство пользователя: Как правильно использовать компилятор

### 1. Инлайн JIT-компиляция (`@topojit`)

Самый простой и рекомендованный способ для ускорения численных расчетов, симуляций, фильтров и обработки сигналов:

```python
from topopyc import topojit
from math import sin

@topojit
def simulate_particle_field(steps: int, dt: float) -> float:
    pos = 0.0
    vel = 1.0
    for i in range(steps):
        force = -sin(pos) * 2.5
        vel += force * dt
        pos += vel * dt
    return pos

# Функция компилируется на лету в машинный код (-O3) при объявлении
# и выполняется напрямую на процессоре:
final_pos = simulate_particle_field(10_000_000, 0.001)
print(f"Результат симуляции: {final_pos}")
```

#### Настройка уровней оптимизации:
```python
@topojit(opt_level="-Ofast")
def ultra_fast_kernel(n: int) -> float:
    ...
```

### 2. Standalone AOT-компиляция в независимый бинарный файл

Если вам нужно создать отдельный исполняемый файл без установленного интерпретатора Python:

```python
from topopyc import TopoCompiler

compiler = TopoCompiler(opt_level="-O3")

def mandelbrot(c_re: float, c_im: float, max_iter: int) -> int:
    z_re = 0.0
    z_im = 0.0
    for i in range(max_iter):
        if (z_re * z_re + z_im * z_im) > 4.0:
            return i
        z_im = 2.0 * z_re * z_im + c_im
        z_re = z_re * z_re - z_im * z_im + c_re
    return max_iter

# Сборка ELF исполняемого файла
compiler.compile_executable(mandelbrot, "./mandel_bin", bench_args=(-0.75, 0.1, 10000))
```

После этого бинарник запускается напрямую:
```bash
./mandel_bin
# [TopoPyc Standalone] Kernel: mandelbrot | Elapsed: 0.021 ms | Result: 33.000000
```

### 3. Лучшие практики написания компилируемого кода (Best Practices)

- **Используйте аннотации типов для аргументов функции** (`x: float, n: int -> float`). Это позволяет топологическому пучку мгновенно зафиксировать граничные стебли $\partial X$ без необходимости промежуточного динамического кастинга.
- **Используйте встроенные функции математики** из модуля `math` (`sin`, `cos`, `tan`, `sqrt`, `exp`, `log`, `fabs`). Компилятор заменяет их на быстрые процессорные инструкции FPU/SIMD.
- **Поддерживаемые управляющие конструкции**: `for ... in range(...)` (с 1, 2 или 3 аргументами), `while <условие>`, `if ... else`, `break`, `continue`, присваивания и составные операторы (`+=`, `-=`, `*=` и т.д.).
